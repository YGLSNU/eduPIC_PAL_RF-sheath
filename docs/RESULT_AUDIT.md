## 자료가 없는 이유

- `261117_initial`은 RF1700 체크포인트에서 끝난 미완료 실행입니다. 입자 이력과 단일 시점 밀도는 있지만 최종 heating·전위/전기장·에너지/이온화·에너지 분포·전극 손실·전력 측정은 없습니다.
- `261119_gap25_V100-300`의 세 전압에서는 정상 방전 측정 전에 전자가 소멸했습니다. 입자 이력과 그로부터 환산한 체적평균 밀도는 제공하며, 빈 방전 상태를 정상상태 측정으로 표시하지 않습니다. 총괄과 상세 4개 페이지에서 각각 6개 진단에 이 사유를 표시합니다.

## 해석·단위 확인

- 75 mTorr 기본 실행은 원본 10 Pa = 75.006 mTorr이며 **하부 RF / 상부 접지**입니다. 20 mTorr 조건군은 **상부 RF / 하부 접지**이고, 손실 진단 중 75.006 mTorr 압력 대조 조건도 상부 RF입니다.
- 기본 측정 5 RF는 RF1701–1705, 120 RF는 RF1706–1825입니다. 120 RF의 기존 EEPF·IEDF는 표시된 동일 길이 블록 평균 정의를 유지합니다.
- 기본 실행 전력 그림은 원본의 위상 평균 j × 위상 평균 E에서 얻은 W/m³입니다. 완전한 입자 field-work·충돌·벽·저장 에너지 수지는 기록되어 있지 않습니다. 기본 전극 flux는 원본 `info.txt`의 반올림된 출력값을 측정 RF 길이로 가중 평균한 값입니다.
- `loss-check`의 각 조건은 **5 RF 과도구간**입니다. 서로 다른 재시작 시점이 포함되어 있어 정상상태 전압 비교로 해석할 수 없습니다. 압력만 바꾼 직접 대조는 250 V·RF1–5의 20/75.006 mTorr 두 조건입니다.
- 진단 실행에서는 매 RF의 전자·이온 수 변화 = 이온화 생성 − 전극 흡수 관계를 확인했습니다. 전극 flux는 흡수 사건 수·가중치·면적·측정 시간으로 환산하며, 전력은 기록된 field-work와 손실·전자 저장 에너지 변화를 W/m²로 표시합니다. 모든 에너지 저장·손실 항을 포함하는 완전한 폐합은 아닙니다.
- EEPF는 eV⁻³ᐟ², 정규화 IEDF는 eV⁻¹입니다. 원본 위상 배열의 유한값·크기, j×E 관계, 평균 밀도와 프로파일의 일치, 에너지 분포 정규화를 확인했습니다.

## 재발 방지와 보존 범위

`audit_coverage.py`가 8개 진단 각각에 그림·실제 상세 링크·측정 불가 사유 중 하나가 있는지 확인합니다. 그림이 메타데이터에만 있고 실제 보고서의 해당 절에 표시되지 않는 경우도 오류로 처리합니다. 업로드 도구와 목록 동기화에 같은 검사를 적용했습니다.

`verify_reports.py`는 위 검사에 더해 북마크에서 상세 보고서까지의 도달 가능성, 파일 링크, 이미지 경로, 다운로드 크기와 SHA256을 확인합니다. 후처리는 `backfill_saved_reports.py`에 보관했습니다.

이번 변경은 저장된 자료의 후처리와 보고서 보완입니다. PIC/MCC 계산을 새로 실행하지 않았으며, 기존 ZIP·재시작 자료·물리 계산 소스는 보존했습니다. 새 그림과 CSV는 기존 ZIP을 교체하지 않고 보고서 폴더에 추가했습니다.
