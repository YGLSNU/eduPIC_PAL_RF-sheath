# 저장 상태에서 계산을 이어가는 방법

`picdata.bin`에는 입자 위치·속도, 누적 RF주기 수와 물리 시간이 있습니다. 단순 그림이나 CSV만으로는 재개할 수 없습니다.
같은 원본 `C/eduPIC.cc`와 물리·수치 조건을 사용해야 합니다. C, C++, Rust 사이에 체크포인트를 교환하지 마세요.

1. 보관할 구간 ZIP과 원본 소스가 있는 시작 체크포인트 ZIP을 내려받습니다.
2. 새 작업 폴더를 만들고 원하는 구간의 `picdata.bin`과 `source-eduPIC.cc`를 복사합니다.
3. Linux/macOS 등 C++ 컴파일러 환경에서 아래 명령을 실행합니다.

```bash
g++ -std=c++11 -O3 -march=native source-eduPIC.cc -o edupic
./edupic 20 m > run.log 2>&1
```

`20`은 **추가 계산할 주기 수**입니다. 1,825주기 상태였다면 1,826–1,845주기를 측정합니다.
`0`은 처음부터 초기화하는 명령이므로 재개할 때 사용하지 마세요.
실행이 정상 종료되면 새 `picdata.bin`, 15개 DAT와 `info.txt`가 생깁니다. 원래 구간은 별도 폴더에 보존하세요.
원본 프로그램은 시작 파일과 진단 파일을 같은 이름으로 덮어씁니다.

## 이번 자동 실행

`run_adaptive.py`는 20주기 구간마다 다른 폴더를 만들고 검사·체크포인트를 저장합니다.
`STOP_AFTER_BLOCK`이라는 빈 파일을 실행 폴더에 만들면 현재 20주기 구간을 마친 뒤 멈춥니다.
정상적으로 중단한 실행은 그 파일을 제거하고 동일한 관리 스크립트를 다시 실행하면 마지막 검증된 구간에서 재개합니다.
자동 수렴 종료 후 같은 스크립트를 재실행하면 추가 계산을 하지 않습니다. 그 경우 새 계산 폴더에서 원하는 체크포인트로 시작하세요.
환경이 교체되거나 강제 종료돼 부분 구간이 남으면 그 부분 폴더를 보존한 채 마지막 검증된 체크포인트부터 다시 진행합니다.

## 알아둘 차이

- 정상 구간 종료 때 체크포인트가 저장됩니다. 실행 중 강제 종료하면 그 구간의 진도·측정 누적은 잃을 수 있습니다.
- RNG 상태는 원본 파일에 없으므로 재시작 후 개별 입자 궤적이 연속 실행과 정확히 일치하지 않습니다.
- 원본 진단 누적은 매 실행마다 0에서 시작합니다. 체크포인트를 읽는다고 기존 측정 통계가 자동으로 합쳐지지는 않습니다.
- 선형 평균, 밀도 가중 에너지, 위상 평균의 곱인 jE, 정규화 에너지 분포는 각각 올바른 결합 방법이 다릅니다.
- 물리 조건을 바꾼 후 기존 입자 상태를 초기값으로 쓰는 것은 가능하지만 새로운 조건에서의 수렴을 다시 확인해야 합니다.
- 나중에 관심 조건 하나만 골라 오래 측정할 때, 그 조건에 대응하는 체크포인트와 소스·설정을 함께 선택하면 됩니다.
