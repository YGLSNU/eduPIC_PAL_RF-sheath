# BRH 진단·자료 해석 기준

이 스캔은 **bounce resonance heating**을 탐색합니다. 단일 beam energy나 gap에서의 EEDF 봉우리만으로 BRH를 판정하지 않습니다. 넓은 에너지·방향·출발 위상 분포, 이동하는 쉬스, 충돌에 따른 방향·에너지 변화를 PIC/MCC 궤적으로 함께 취급합니다.

## 측정 정의

| 자료 | 정의 / 범위 |
|---|---|
| 전자 UID | 출생부터 벽 소실까지 고유 번호. ionization 자식에는 parent UID도 저장. loss 시 배열 교환에도 유지 |
| 추적 표본 | UID의 결정적 hash로 약1/16. 물리 난수 추첨과 독립이며 추가 RNG를 사용하지 않음 |
| 쉬스 접근·반사 | x/L=0.25 또는0.75 기준면 안으로 들어간 뒤 같은 쪽 quarter-gap에서 전기장 kick에 의한 vx 반전, 그 지점 ne/ni<0.8, 이후 기준면 바깥 방향으로 재통과한 사건 |
| 왕복 | 같은 UID의 같은 쪽 기준면 출구 두 사건 사이에 반대편 유효 쉬스 반사가 있는 구간. tau는 두 출구 시각의 차이 |
| 기본 공명 근접 | abs(tau/T_RF−1)≤0.10. 연속2회 이상을 위상 반복 후보로 집계. **에너지 증가 여부와 독립적으로 선정** |
| 주 분석 | 상부 RF 쪽 출구→상부 RF 쪽 출구. 양쪽 왕복의 일을 더해 같은 궤적을 중복 계산하지 않음 |
| 전기장 일 | 각 leapfrog vx kick의 정확한 운동에너지 차를 누적한 **signed W_field**. 음수도 보존 |
| 충돌 변화 | 실제 MCC 전후 parent 전자의 운동에너지 차. 탄성/여기/이온화 횟수를 구분하며 충돌한 왕복도 포함 |
| 에너지 폐합 | 같은 parent를 따라 ΔK_staggered=W_field+ΔK_collision_parent. ionization 때 daughter로 넘어간 에너지는 parent 손실에 포함 |
| EEDF·EEPF | 전체 전자에서 위상 bin마다1번 시간 표본. 위치20구간×방향2종×위상200×energy271bin의 원시 수. 전체 E와 Ex를 별도 저장 |
| 에너지 해상도 | 0–10eV:0.1eV,10–100eV:1eV,100–500eV:5eV,≥500eV overflow. 원시 수를 합친 뒤 ΔE로 정규화. EEPF=PDF/sqrt(E) |
| 전력 지도 | 순간 kick 일을 CIC로 위치·위상에 쌓아 W/m³ 환산. 원래 코드의 **phase-mean j×phase-mean E**와 별도 표기 |
| 연속 probe | x/L=0.25,0.5,0.75에서8step마다 전기장·밀도·전위. 비RF주기 변동 분석용 원자료 |

왕복 에너지 장부는 **반 step 속도**로 이산 운동량 갱신과 정확히 맞춥니다. EEDF는 원래 코드의 동기화된 속도를 사용합니다. 회전점은 vx≈0이므로 그 지점의 Ex를 빔 출발 에너지로 부르지 않습니다.

quarter-gap 기준면과 ne/ni=0.8은 재현 가능한 **탐색용 정의**입니다. 실제 쉬스가 기준면을 넘으면 검출이 불완전해질 수 있습니다. 검출 왕복 분율은 전체 전자의 BRH 밀도 분율이 아닙니다. 양쪽 쉬스에 도달하지 않은 전자와 기록 경계에서 잘린 왕복은 사건 분모에 포함되지 않습니다. 표본 수와 검출 범위를 보고서에 명시합니다.

## 수렴·중단

마지막600RF를3×200RF로 나눠 전자·이온 평균 입자 수 span<1%,600RF fitted drift<2%를 요구합니다. 이후 **새로운 최소200RF**를20RF 블록으로 측정합니다. 평균량·밀도3%, heating 지도5% 기준과 BRH 사건 통계를 별도로 확인합니다. BRH 분율 탐색 허용치는 상대10% 또는 절대0.5%p입니다. 드문 사건이나 signed 평균≈0에는 상대 오차 하나만 적용하지 않습니다.

최대1000RF 진단 또는 총20000RF에서 기준을 못 맞추면 미충족 중단으로 남깁니다. 전자0이면 소멸로 종료합니다. density 안정만으로 EEDF 꼬리·위상 집단의 수렴을 가정하지 않습니다. 통계 지표는 격자·모델 오차를 보증하지 않습니다.

후보 signed work의 허용치는 상대10% 또는 절대0.1eV/왕복 중 큰 값이며, 후보100사건·고유 UID30개 이상도 요구합니다. 분율은 전체 상부 왕복1000사건·고유 UID100개 이상에서 평가하며, 희귀 사건을 놓친 0분산을 과신하지 않도록 고유 UID 수에 따른3/N 항을 추가합니다. 20RF 및40RF 블록 추정 중 큰 불확실도를 사용하고 첫/뒤 절반의 변화를 확인합니다. 수치 정밀도 충족은 **가열 증대나 BRH 존재의 판정**과 별개입니다.

## BRH 판정 수준

1. 왕복 시간 분포·출발/재도착 위상·연속성으로 공명 근접 전자를 확인합니다.
2. 충돌 없음/탄성만/비탄성 포함을 나누되 전체에서도 signed W_field와 순에너지 변화를 비교합니다. positive gain만 고르지 않습니다.
3. gap에 따른 반복 집단과 에너지 전달 증대가 함께 나타나는지 봅니다. 단일 임계 gap보다 넓은 공명 대역이 나올 수 있습니다.
4. 후보에서 시간격자·입자 수·독립 seed, 기준면·위상 허용폭·연속왕복 횟수 민감도, 인접 gap과 필요시 주파수 detuning을 검증합니다. 초기 스캔만으로 이 추가 검증이 끝났다고 표시하지 않습니다.

한 번 통과한 beam, ionization 줄무늬 기울기, 초기 위상 bunching은 반복 왕복 증거를 대체하지 않습니다. 재료벽은 흡수 경계로 두고 **쉬스 전기장 반사**만 관찰합니다.

원본 알고리즘: Z. Donko et al., *eduPIC: an introductory particle based code for radio-frequency plasma simulation*, Plasma Sources Science and Technology **30**, 095017 (2021). 추가 BRH 기준은 이번 실행의 진단 정의이며 원 논문의 BRH 검증 결과가 아닙니다.
